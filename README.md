## 🚀 Como editar

1. Clone o repositório:
   ```bash
   git clone https://github.com/DREAMxVP/dreamxvp.github.io.git
   cd dreamxvp.github.io
   ```

2. Abra com um editor de código (VS Code, etc.)

3. Edite os arquivos:
   - **index.html** — conteúdo e estrutura
   - **css/style.css** — cores, layouts, tipografia
   - **js/script.js** — interatividade

4. Teste localmente com um servidor HTTP (ex.: Five Server, Live Server, Python `http.server`)

5. Faça commit e push:
   ```bash
   git add .
   git commit -m "descrição das mudanças"
   git push origin main
   ```

## 🔄 Atualizações automáticas

Após fazer push para `main`, o site é publicado automaticamente em **https://dreamxvp.github.io** (pode levar alguns minutos).
